# Triage Labels

skills 用五個標準角色描述 issue 狀態；本 repo 直接沿用預設字串，寫在 issue 開頭的 `Status:` 行。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage`    | `needs-triage`    | 使用者還沒評估 |
| `needs-info`      | `needs-info`      | 等使用者補資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格清楚，AI 可以直接做 |
| `ready-for-human` | `ready-for-human` | 需要使用者本人處理（例如在 App Store Connect 操作、實機測試） |
| `wontfix`         | `wontfix`         | 不做 |
