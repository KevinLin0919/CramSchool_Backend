# 紅筆對照：批完一頁只顯示要訂正的格子

Status: active
Repos: CramSchool_IOS
Implementer: Claude

## Problem Statement

老師希望掃完一頁後先停下來，用紅筆把錯的地方寫在考卷上，再翻到背面。「一頁批完自動翻頁」開關本來就能關掉，
但光是停下來不夠：鏡頭對不到考卷約 0.5 秒，畫面上的框就全部消失，所以老師一放下手機去拿紅筆，答案就不見了。
另外，批完的一頁上同時有綠、紅、橘、白四種框，看起來像亂畫，真正要訂正的兩三格反而不顯眼。

## Solution

1. **即時畫面的精簡模式**：目前這一頁每一格都判定完之後，綠框和白色待批框隱藏，只留紅框（錯）和橘框（待確認）。
   紅框實線、不填色；橘框虛線、不填色，標籤前加「?」。掃描中維持原樣，因為那時老師需要看到進度。
2. **標籤固定在框的右邊**（右邊放不下才放左邊），寫正確答案。原本放在框的左上方，會蓋住上一行的印刷。
3. **紅筆對照畫面**：「一頁批完自動翻頁」關掉時，一頁批完約 0.6 秒後跳出一張定格的母卷圖，只畫紅框、橘框和正確答案，
   標題列出「錯 N・待確認 M」，按鈕是「收起」和「翻到背面」（還有沒批完的頁時）。不依賴鏡頭對位，手機可以放下照著抄。
   沒有要訂正的一頁不會跳出。

## 不做的事

- 不改判定結果、不改自動翻頁的條件。
- 結果頁（`ResultsView`）的顯示不動。
- 自動翻頁開著時不顯示紅筆對照。

## 驗證

- CI 編譯與示範掃描自我測試。
- QAT 實機：關掉自動翻頁，掃一份兩面考卷，確認正面批完會跳出紅筆對照、只有紅橘框、答案在框右邊；按「翻到背面」能切頁；
  最後一頁批完時紅筆對照蓋在完成卡片上面，收起後看得到完成卡片。
